五项大功能

伴

读伴，同行一段路重做

同行卡上看见 TA 今天读没读；轻拍、击掌、送一句，每天一点点的陪伴。两个人都读完时，中间的连线会亮起来。

邀

自己挑一位读伴全新

从本期学员里挑一位发出邀请，对方同意才结成。最近读过的人排在前面，不想被邀请也可以关掉。

信

来信，书友写给你的话全新

「通知」改名「来信」。谁想到了你，一眼可见；想看小凡看见，直接在来信里同意或婉拒。

记

随喜记，把触动随手记下升级

沉静阅读里长按一段，选「记一条随喜」，这句话和课程自动带上。能搜索，也能一键做成日签。

签

日签，把晨读带给朋友升级

日签可以发朋友圈；图上是你专属的小程序码。朋友因你而来，你会收到一封来信。
