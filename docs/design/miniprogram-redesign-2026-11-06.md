# 小程序视觉升级方案

## 背景

2026-11-06 对小程序 41 个注册页面做了代码级设计审计：主包核心页面已经有暖纸质感、租户主题色和部分骨架屏，但样式分散、主题变量覆盖不足、交互反馈和状态设计不均衡。分包中的在场、播客、活动和移动管理页面与主链路视觉差异较明显。

## 总体判断

值得升级，但不建议一次性推倒重做。推荐两阶段：

1. **版本一：主链路统一升级**。先建立设计基础，并升级首页、晨读营、我的、课程阅读、报名与支付等高频页面。
2. **版本二：全端一致性补齐**。再处理打卡、小凡看见、在场、活动、通知、报告、移动管理和低频页面。

## 版本一范围

### 1. 设计基础

- 扩展全局设计令牌：字号、间距、圆角、阴影、反馈色、禁用态、主/次按钮。
- 增加通用样式类：页面壳、卡片、标签、主按钮、次按钮、骨架屏、空态、错误重试、安全区底部容器。
- 保留微信小程序原生框架和 WXSS，不引入第三方 UI 框架。
- 保留租户主题机制，通过 `--theme-*` 适配凡人共读、若星生活家和超人读书会。

### 2. 主 Tab

#### 首页

- 收敛顶部信息，突出用户、当前期次和累计打卡。
- 今日任务作为第一视觉焦点，次级入口降低视觉强度。
- 主要按钮统一为主行动样式，已完成为确认态。
- 页面进入增加轻微 stagger 动画，保留现有业务结构。

#### 晨读营

- 强化页头的编辑感与主色氛围。
- 课程卡统一封面、标题、状态、进度和行动区对齐。
- 已报名、去报名、未报名状态使用统一标签样式。
- 保留现有骨架屏并调整为设计系统样式。

#### 我的

- 用户卡改为数据概览卡，头像、昵称、手机号和累计打卡更清晰。
- 设置分组使用统一列表细胞样式，减少 emoji 图标混乱。
- 管理员入口与普通设置在视觉上分层。

### 3. 学习与转化主链路

#### 课程详情

- 统一课程标题、模块标签和内容区域的阅读层级。
- 自定义课程模块和七个习惯固定模块使用同一套标题、分隔和留白。
- 底部操作统一安全区和按压反馈。

#### 沉浸阅读

- 强化沉浸页纸面质感，优化标题、正文宽度、行高和模块间距。
- 顶部进度与底部操作保持轻量，不干扰阅读。

#### 报名

- 报名页改为收据式信息卡 + 表单卡结构。
- 根据报名模板保持动态字段，但统一字段标签、输入框、错误和必填样式。
- 底部提交按钮固定在安全区，避免长表单时丢失主行动。

#### 支付

- 订单信息改为收据式布局，金额使用大号表格数字。
- 支付方式选择统一为可点击卡片，选中态清晰。
- 支付按钮、返回按钮和结果弹窗接入统一样式。

## 验收标准

1. 版本一覆盖上述页面，且不改变现有接口、业务判断和路由。
2. 核心页面视觉使用全局令牌，避免新增散落的品牌色硬编码。
3. 主要可点击区域具备按压或选中反馈。
4. 表单和列表的关键页面具备加载、空态或错误反馈。
5. 小程序相关 Jest 测试通过，主题色扫描和样式语法检查通过。
6. 三租户切换后主色和品牌文字正常，不出现明显样式断裂。

## 暂不处理

- 不更换小程序框架。
- 不引入自定义字体文件，避免包体和加载风险。
- 不重写业务逻辑。
- 不做全局深色模式。
- 版本二再处理分包页面、移动管理页和完整空态/错误态补齐。

## 版本二范围

版本二在版本一基础上做全端一致性补齐，不改变页面信息架构和业务逻辑。

### 1. 全局一致性

- 将剩余页面统一接入暖纸背景、租户主色和全局圆角/阴影/字号体系。
- 统一列表卡、表单卡、筛选 chip、空态、加载态、固定底部操作和 FAB 的视觉语言。
- 保留页面现有类名和组件，采用低风险 WXSS 覆盖，不做大规模结构重写。

### 2. 覆盖页面组

- **学习与打卡**：课程列表、打卡、打卡日记、分享、排行、成员、他人主页。
- **小凡看见**：列表、详情、编辑、申请。
- **在场与活动**：在场列表/详情/发布、活动列表/详情、我的活动、优惠券。
- **通知与报告**：通知、提醒设置、实录报告列表/详情。
- **音频与协议**：播客播放器、会议 webview、隐私政策、用户协议。
- **登录与邀请**：登录、邀请页、编辑资料、期次详情。
- **移动管理**：管理工作台、活动报名、数据分析、课节小凡看见。

### 3. 验收补充

1. 除 webview 外，每个页面样式文件包含版本二一致性标记并使用全局令牌。
2. 长页面固定底部操作和 FAB 尊重安全区。
3. 主要列表和表单具备按压反馈。
4. 小程序全量 Jest、主题色扫描和 OpenSpec 校验通过。

### 4. 颜色例外与保护

- 登录页保持租户主色整屏背景和白色登录卡，不使用浅色整屏背景。
- 打卡页自定义导航保持租户主色，页面主体保持暖纸背景。
- 「在场」是产品子品牌：列表、详情、发布页导航栏、筛选选中态和发布按钮继续使用在场深绿色 `#2D5A3D`，不被租户主题同步覆盖。
- 在场头像文字使用 `line-height: 1` 与 flex 居中，避免单字偏移。
