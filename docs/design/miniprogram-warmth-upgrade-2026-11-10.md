# 小程序「晨光」温暖升级方案（视觉与交互 · 版本三）

- 状态：三批均**已实现、未提交**（2026-11-10），待在开发者工具和真机上验收；实施中与方案的出入见文末「实施记录」
- 前置：版本一、二已完成，见 `docs/design/miniprogram-redesign-2026-11-06.md`
- 预览稿：`docs/design/miniprogram-warmth-preview-2026-11-10.html`（浏览器直接打开，含现状与方案对照）
- 姊妹篇：`docs/design/miniprogram-feature-upgrade-2026-11-10.md`（功能升级方案）
- 范围：小程序前端的样式、少量结构和文案；涉及后端的两处单独标出

## 一、结论

有升级空间，而且现在缺的不是「统一」，是「温度」。

11-06 的两轮改版把 41 个页面收进了同一套设计令牌，这一步已经做完。现在打开小程序，感觉是「一个整洁的学习工具」，还不是「一个清晨一起读书的地方」。差距集中在三处：

1. **色温偏冷。** 页面底色是偏青的灰白（`#f3f6ef`），文字是墨绿黑，每页顶上还有一整条品牌蓝导航栏，全局没有一个暖色。暖纸色只在沉浸阅读和「在场」里出现过。
2. **首屏不是「晨读」。** 首页第一屏是头像、昵称、签名和一个数字，本质是个人名片。它不知道现在是清晨，也不告诉你今天是第几天、读什么。
3. **关键时刻没有自己的样子。** 打卡成功是 7 套动画随机出（火箭、碎片、聚光灯），和晨读的气质没关系；读完一课、收到小凡看见，也都只是普通页面。

这一轮建议叫「晨光」，做三件事：**换一张暖的纸、把首屏还给今天的晨读、给几个关键时刻做仪式**。全部沿用现有 `--app-*` 令牌和租户主题机制，不换框架、不加字体文件、不动业务逻辑。

## 二、需要你确认的 6 件事

| # | 要定的事 | 我的建议 | 如果不这样 |
| --- | --- | --- | --- |
| 1 | 中性色整体从「青灰」换成「暖纸」（影响所有页面） | 换。这是温度的来源，改的是令牌，回滚也只是改回令牌 | 只改首页，其余页面仍偏冷，进出首页会有割裂感 |
| 2 | 增加一个三租户共用的「晨光」辅色（琥珀橙），只用于时间和仪式，不用于按钮 | 加。品牌主色继续管操作，晨光色只管「光」 | 温暖感只能靠底色，仪式时刻没有记忆点 |
| 3 | 内容页导航栏从整条品牌色改为纸色深字 | 改。品牌色留在首页、晨读营页头、登录、打卡这些品牌时刻 | 保守版：导航栏不动，只改页面内部（效果约打六折） |
| 4 | 首页首屏改成「今天的晨读」，个人签名移到「我的」 | 做。首屏给问候、第几天、今日一句和一个主行动 | 保留名片式首屏，只换配色 |
| 5 | 标题和数字启用衬线体（用系统自带字体，零字体文件） | 做，真机看过再定。数字全平台生效；中文标题 iOS 生效，安卓自动回退黑体 | 全部保持黑体，「书卷气」少一半 |
| 6 | 凡人共读主色 `#4a90e2` 要不要调 | **本轮不动**。它牵连 logo、Tab 图标、分享封面，属于品牌决定 | 想调的话单开一轮，三租户一起评估 |
| 7 | 登录页：从「主色整屏 + 白卡」换成「破晓」登录 | 换。上半屏仍是租户主色，往下渐亮成晨光，登录区落在暖纸上 | 保守版：保持主色整屏和白卡，只加晨光光晕、换掉 emoji |
| 8 | 打卡页导航：从主色条换成纸色页眉 | 换。内容页都改纸色后，它保持主色反而成了例外；主色留给「发布」按钮 | 保持主色条 |
| 9 | 「在场」：保留深绿身份，并入同一张纸 | 换。深绿只做强调色；列表页保留深绿导航，详情和发布页改纸色 | 完全不动（会出现两种略有差别的米色） |

第 1–6 项按 11-10 的回复记为已确认；第 7–9 项是放开保护项后新增的，详见第七节。

## 三、现状诊断

### 已经做对的（保留并放大）

- 设计令牌已经成体系：页面样式里 `var(--app-*)` 854 处、`var(--theme-*)` 614 处，按压反馈、卡片、按钮都有统一类。
- 沉浸阅读页已经是暖纸（`#fffdf8`），读起来舒服；「在场」有自己完整的暖色子品牌（深绿 + 赭石 + 米纸）。这两处证明暖色在这个产品里是成立的。
- 课程模块用单字做图标：静、问、学、读、看、想、记、摘、说。这是整个小程序最有辨识度的视觉元素，现在只是蓝色小方块，没被当成资产用。
- 已经有几句好文案：「趁早上安静的 10 分钟，咱们一起读完今天这一课」「能耐心读到这里，就是今天很扎实的一步」。这就是该有的口吻，只是没有贯穿全局。

### 还显得「冷」的地方

| 现象 | 证据 | 带来的感受 |
| --- | --- | --- |
| 中性色偏青、偏冷 | `app.wxss:8-20`：底色 `#f3f6ef`、文字 `#172019`、阴影 `rgba(37,60,43,…)` 都带绿 | 干净，但像工具后台 |
| 全局没有暖色令牌 | `app.wxss` 里唯一的暖色是 `--app-warning`（语义是警告） | 「晨」没有颜色 |
| 每页一条品牌蓝导航 | `app.json` 全局导航 `#4a90e2`，另有 9 个页面在页面级又写了一遍 | 第一眼永远是一块饱和的蓝 |
| 首屏是个人名片 | `pages/index/index.wxml:12-42`，根节点类名就叫 `page-profile` | 进来不知道今天要做什么 |
| emoji 当图标 | WXML 里 80 处彩色 emoji、45 种（📋📝✨📬📆🌿🔔…），分布在 28 个文件 | 各机型长得不一样，像占位符 |
| 只有一种字体 | 全局一个黑体栈（`app.wxss:49`），标题、正文、数字没有区别 | 读书产品没有「书卷气」 |
| 打卡庆祝风格跑偏 | `pages/checkin/checkin.wxml:211-352`：能量爆发、碎片裂变、聚光登场、火箭升空等 7 套 | 热闹，但不像晨读营 |
| 几乎没有触感 | 全小程序只有 1 处 `wx.vibrateShort`（在场发布） | 点赞、打卡成功手上没感觉 |
| 「我的」只是设置页 | `pages/profile/profile.wxml` 全是设置项；连续天数后端有（`User.currentStreak`），前端没展示 | 23 天的坚持没有地方被看见 |
| 文案功能化 | 33 处「暂无…」、38 处「加载中」；打卡成功语是「打卡成功！坚持就是力量！」；他人主页默认签名是「知名心灵大师」 | 像系统在说话，不像人在说话 |
| 空态和加载偏原始 | 首页、我的用整屏转圈；页面里只有期次列表用了骨架屏 | 等待时没有品牌感 |

## 四、设计方向：晨 · 读 · 营

把「晨读营」三个字各自翻译成一条设计原则：

- **晨 → 光。** 界面知道现在几点。清晨是暖金色，白天是纸色，夜里是深蓝和月亮。23 天的进度用「太阳一点点升起」来表达。
- **读 → 纸。** 暖纸底、暖墨字、衬线标题，把现有的单字图标做成印章。少用色块，多用留白和细线。
- **营 → 人。** 能看到同行的人（谁已经读完、今天第几位打卡），文案像营里的人在说话。

一条取舍规则：**品牌主色管「做什么」（按钮、选中、链接），晨光色管「此刻」（时间、进度、庆祝）。** 两者不混用，这样三个租户换主色后都成立——蓝配金是破晓的天，绿配金是清晨的林子，橙红配金是同一家人。

## 五、方案明细

### A. 色温与质感（改令牌）

改 `app.wxss` 的中性色令牌，并新增晨光色。数值都算过对比度：

| 令牌 | 现在 | 建议 | 说明 |
| --- | --- | --- | --- |
| `--app-page-bg` | `#f3f6ef` | `#f6f1e7` | 青灰 → 暖米 |
| `--app-page-bg-deep` | `#e9efe7` | `#efe7d8` | |
| `--app-paper` | `#fffefa` | `#fffdf8` | 与沉浸阅读页统一 |
| `--app-paper-muted` | `#f7f6ed` | `#faf5ea` | |
| `--app-surface-muted` | `#f8faf4` | `#f8f3e8` | |
| `--app-text` | `#172019` | `#2b2622` | 墨绿黑 → 暖墨，纸上对比度 14.7:1 |
| `--app-text-soft` | `#526055` | `#62584d` | 6.8:1 |
| `--app-text-muted` | `#8a948b` | `#776c5f` | **现在只有 3.1:1（偏淡），改后 5.1:1** |
| `--app-border` / `--app-rule` | `rgba(49,72,56,…)` | `rgba(92,70,44,…)` | 绿调 → 褐调 |
| `--app-shadow*` | `rgba(37,60,43,…)` | `rgba(84,60,30,…)` | |
| `--app-dawn`（新） | — | `#ee9b45` | 晨光主色，只用于图形（太阳、进度、光晕） |
| `--app-dawn-soft`（新） | — | `#fdf0dc` | 晨光浅底 |
| `--app-dawn-ink`（新） | — | `#8a4b12` | 晨光底上的文字，6.0:1 |

配套要做一次硬编码清扫，否则会留下冷色补丁：页面样式里还有 55 处写死的绿调 `rgba(49,72,56…)`（33 个文件）和约 80 处冷灰色值（`#eef2f7`、`#f5f7fa`、`#8c97a8` 等）。

顺手修一个可读性问题：白字压在主色 `#4a90e2` 上对比度只有 3.3:1，小字按钮建议统一用 `--theme-primary-dark` 做底（4.7:1）。

### B. 导航栏与 Tab 栏

- **内容页**（课程详情、小凡看见、打卡日记、通知、我的等）导航改为纸色 `#fffdf8` + 深色文字，像书页的天头。
- **品牌时刻**保留主色：晨读营页头、登录页上半屏、「在场」列表页（深绿）。打卡页导航改为纸色，详见第七节。
- **首页**导航底色跟随时段，与首屏顶部同色（用 `wx.setNavigationBarColor`，不改自定义导航，风险低）。
- Tab 栏底色 `#ffffff` → `#fffdf8`，去掉黑色分隔线。

技术注意：`miniprogram/scripts/apply-tenant.js:159-181` 会在切租户时把页面级导航色统一改回租户色（目前只豁免自定义导航和「在场」）。改纸色导航要同步给它加一份「纸色导航页」名单，否则一构建就被覆盖。

### C. 字体（零字体文件）

- 新增 `--app-font-serif: "Songti SC", "STSong", "Noto Serif CJK SC", serif`，用于期次名、课程标题、今日一句、小凡的信。iOS 自带宋体；安卓多数机型没有中文衬线体，会自动回退到黑体，不会出错，只是少一层效果。
- 新增 `--app-font-num: Georgia, "Times New Roman", serif`，用于「第 7 天」「连续 5 天」这类大数字。iOS 和安卓都有对应的衬线数字。
- 正文、按钮、表单保持黑体不变。
- 这不违反 11-06「不引入自定义字体文件」的决定；鸿蒙和安卓的实际效果需要真机确认后再定用到多大范围。

### D. 图标：印章 + 线性图标，替换 emoji

- **印章**：把「静问学读看想记摘说」的做法扩展成全局组件 `.app-seal`——暖纸底、细边框、衬线单字。首页板块标题同步换成印章：今日晨读「晨」、我的打卡「记」、小凡看见「见」、请求看见「请」、凡人生活「在」、近期活动「聚」。纯文字实现，零图片，各机型一致。
- **线性图标**：铃铛、编辑、搜索、分享、播放、点赞、评论、日历、定位、锁等约 16 个功能图标，用内联 SVG 遮罩实现（项目里已有同类做法：`pages/index/index.wxss` 的 `book-icon-svg`），颜色跟随文字色和主题色。
- 保留 emoji 的地方：用户自己输入的内容、后台配置的期次图标。

### E. 首页：从「个人名片」到「今天的晨读」

首屏结构（详见预览稿）：

1. **晨光问候区**：「早安，{昵称}」+ 日期 + 「{期次名} · 第 7 天」。背景随时段变化：破晓（5–8 点，暖金）、白天（纸色）、黄昏（柔粉橙）、夜晚（深蓝 + 月亮，文字反白）。只有这一块区域变色，不是深色模式。
2. **旅程进度**：一条地平线，23 个刻度，太阳停在今天的位置。配一行小字：「连续晨读 5 天 · 累计 42 天」。
3. **今日晨读卡**：课程标题（衬线）+ 今日一句（取课程「摘一摘」的内容，没有则不显示）+ 已打卡书友头像 + 三步进度（读 → 记 → 听）+ **一个**主按钮。主按钮按状态变化：开始晨读 → 去打卡 → 今日已完成。现在的四个并排按钮（去晨读 / 去打卡 / 去播客 / 看实录）降为卡片下方的文字入口。
4. 下方板块（我的打卡、小凡看见、请求看见、凡人生活、近期活动）顺序和显隐仍由后台首页配置决定，只换标题样式和卡片质感。

头像缩小放到右上角，点击仍可编辑资料；个人签名移到「我的」页头。

### F. 打卡与读完：晨光仪式

- 现有 7 套庆祝里最接近的是 C「光芒升起」。建议把 C 升级成晨光仪式：太阳从地平线升起，中间是大号数字「第 7 天」，下面三行——连续天数、「你是今天第 9 位打卡的书友」、后台配置的寄语。两个按钮：「看看大家的打卡」「分享今日打卡」。
- 配一次中等强度的震动。
- **不动后端**：样式仍叫 C，后台的庆祝配置照常可用。建议各租户后台默认只启用 C（晨光）和 B（书页翻飞），其余样式保留但不默认。
- 沉浸阅读的读完提示同步成同一套视觉（小一号），让「读完」和「打卡」像同一个仪式的两步。
- 打卡编辑页：输入框提示语从「请输入日记内容...」改成当天课程的「想一想」问题，没有则用「今天读到哪一句，让你停了一下？」。

### G. 「我的」：从设置页到晨读手账

- 页头：头像、昵称、签名（可点改）。
- 三个数字（衬线）：累计、连续、最长。
- **晨读日历**：当月格子，打过卡的日子点亮，今天用晨光色标出。
- **共读足迹**：读过的每一期是一枚印章（韧、协、同、秩、自…），进行中的那期是空心章加进度。
- 原有设置项收在下方，分组不变，加线性图标。

**涉及后端（两处）**：

1. **口径校准**：现在「累计打卡 N 天」实际是打卡条数（`backend/src/controllers/user.controller.js:39` 用 `Checkin.countDocuments`），而打卡不限每天一次（`backend/src/controllers/checkin.controller.js:376`），一天打两次会算成两天；连续天数同理会被重复累加，断卡后也要等到下次打卡才归零。把这些数字放大展示之前，要先改成按自然日去重。
2. **日历数据**：需要一个按月返回打卡日期的只读接口（或复用现有打卡列表接口在前端聚合，数据量小时可行）。

这一项因此排在第三批。

### H. 课程详情与沉浸阅读

- 课程详情顶部加一条细的「九步」进度：静 · 问 · 学 · 读 · 看 · 想 · 记 · 摘 · 说，滚到哪步亮哪步，点击可跳转。模块标题换成印章样式。
- 底部栏去掉大号「返回」按钮（系统导航已有返回），「去打卡」占满，旁边放一个播客小按钮。
- 沉浸阅读的「Aa」从只调字号，扩成一个小面板：字号、字体（黑体 / 宋体）、纸色（暖白 / 米黄 / 夜间）。

### I. 小凡看见：做成一封信

小凡看见是整个产品情感最重的内容，现在的呈现是带彩色左边框的列表项。建议：

- 列表里每条是一个信封：收信人、期次、日期，未读的带一枚红色火漆点。
- 详情页是信纸：衬线正文、更大的行距，结尾落款「小凡」和日期。
- 首页的小凡看见板块，有未读时显示「小凡给你留了一封信」。
- 弹幕、朗读、长图分享等现有功能位置不变。

### J. 文案口吻

定一条规则贯穿全局：**用「你」不用「您」；像营里的人在说话；不喊口号；出错时说清楚发生了什么、下一步怎么办。**

| 位置 | 现在 | 建议 |
| --- | --- | --- |
| 首页无任务 | 暂无今日任务 | 今天没有安排晨读，好好休息 |
| 打卡输入框 | 请输入日记内容... | 今天读到哪一句，让你停了一下？ |
| 打卡成功 | 打卡成功！坚持就是力量！ | 第 7 天，读完了。明早见。 |
| 退出未发布 | 您编写的日记还未打卡发布，确定要离开吗？ | 这篇还没发布。发布后书友就能看到；丢弃并退出的话，草稿会一并清除。 |
| 评论为空 | 内容为空 | 还没有人留言，说点什么吧 |
| 小凡看见为空 | 暂无反馈 | 小凡还在读你的打卡，写好了会放在这里 |
| 排行为空 | 暂无排行数据 | 今天还没有人打卡，做第一个吧 |
| 他人主页默认签名 | 知名心灵大师 | 这位书友还没写签名 |

先改核心链路上约 30 条，其余随页面改造逐步替换。

### K. 动效、触感、空态、加载

- **动效**：三档时长（按压 120ms、状态切换 220ms、进入 360ms），仪式类 1 秒左右。点赞加一个心形弹跳。尊重系统「减少动态效果」设置。
- **触感**：新增 `utils/feedback.js` 统一封装震动和成功提示。只在四个时刻震动：点赞、打卡成功、读完、长按摘句。
- **提示**：全小程序有 245 处 `wx.showToast`，不全部重写。只把核心链路上的成功提示（约 20 处）换成统一的顶部轻提示，错误提示保持系统样式。
- **空态**：一套线描插画（摊开的书、台灯、信封、小树苗），内联 SVG，每张不到 2KB，配一句话和一个行动按钮，替换现在的「emoji + 暂无…」。
- **加载**：首页和「我的」的整屏转圈换成骨架屏（`app.wxss` 里已有 `.app-skeleton`）；列表页的「加载中...」文字换成骨架行。

## 七、原保护项的新方案与本轮不做

11-06 把登录页、打卡页导航、「在场」列为保护项，是因为当时的一致性改版把它们的品牌感改丢了（登录被改成浅色整屏，在场被租户色覆盖）。这个顾虑仍然成立，所以下面不是「取消保护」，而是用晨光的同一套规则重做，并保住它们原本要保的东西。对照图见预览稿第八至十节。

### 1. 登录页：「破晓」登录

- **为什么换**：整屏纯主色 + 📚 emoji + 悬浮白卡，会成为晨光之后全小程序最「旧」的一屏，而它恰好是新书友的第一眼。
- **方案**：整屏是一幅破晓。上半屏仍是租户主色，由深到浅，像天慢慢亮起来；到地平线处过渡成晨光色，半个太阳升起；地平线以下是暖纸，登录区直接落在纸上，不再是悬浮白卡。
- **渐变路径**：主色 → 主色的浅调 → 暖白，再叠一层晨光光晕。不直接从蓝过渡到橙（中间会发灰），这样蓝、绿、橙红三个租户都成立。
- **徽记**：📚 换成一个白色线描徽记——摊开的书页上升起太阳（内联 SVG）。我原先建议换成租户 logo，看过素材后不可行：三个租户的 logo 都只有 81×81 像素，凡人共读和超人读书会的还是同一个灰色占位图标。以后有高清 logo 再替换。
- **文字**：品牌名和「明理实修，同见同行」用衬线。
- **不变**：协议勾选、快捷登录的流程；「稍后登录」保持清晰可见的按钮形态（审核要求）。
- **保住了什么**：品牌主色仍是第一印象，不是浅色整屏。
- **保守版**：保持主色整屏和白卡，只在底部加晨光光晕、换掉 emoji、标题改衬线。

### 2. 打卡页：纸色页眉

- **为什么换**：11-06 时别的页面都是主色导航，打卡页保持主色是为了一致；现在内容页统一改纸色，它保持主色反而成了唯一的例外。写字的页面也更适合安静。
- **方案**：自定义导航改为纸色，返回箭头和标题用深色；标题下一行小字「第 7 天 · 课程名」，配印章「记」；导航下沿一条晨光色细线。
- **主色去哪**：底部主按钮（文案建议从「每日打卡」改为「发布打卡」）、工具栏选中态、链接。
- **顺带**：编辑区的纯白底和冷灰边框（`#edf1f6`、`#fbfcfe`）换成纸色和暖色细线。
- **技术**：`miniprogram/pages/checkin/checkin.json` 加 `navigationBarTextStyle: black`，让状态栏图标变深色。
- **保住了什么**：这一页的品牌时刻交给打卡成功的晨光仪式（F 节）。

### 3. 「在场」：同一张纸，换一种印泥

- **判断**：三处里它现状最好，深绿配暖纸本身就好看，所以不换身份，只做并入。
- **为什么要动**：全局换成暖纸后，在场自己的米色（`#F5F0E8`）和全局米色（`#f6f1e7`）几乎一样又不完全一样，卡片是纯白、文字是冷灰（`#2C2C2C`、`#888888`）。放在一起会像没调准，而不像子品牌。
- **方案**：
  - 中性色全部改用全局令牌（纸、墨、细线、阴影），在场只在强调色上不同。
  - 深绿做成「作用域内的主题色」：在场页面里把 `--theme-primary` 系列覆盖成深绿 `#2D5A3D`，按钮、筛选、印章、链接自动跟随；赭石 `#C4873A` 并入晨光色系。
  - 导航按全局同一条规则：列表页是在场的门面，保留深绿导航；详情页和发布页是内容页，改纸色。
  - emoji（🌱 💬 🔥 🤗）换成印章和线性图标；印记标题用衬线；日期和地点做成照片角上的一枚邮戳，呼应「印记」。
- **不变**：媒体优先的卡片结构、头像文字居中的修复、切租户脚本对在场的豁免。
- **保守版**：完全不动。

### 排期

打卡页纸色页眉、在场的中性色并入和导航规则放第一批；破晓登录放第二批；在场的邮戳和图标放第三批。

### 本轮不做

- 不换框架，不引入组件库，不加自定义字体文件。
- 不做全局深色模式（只有首页问候区在夜间变深）。
- 不改租户主色、logo、Tab 图标图片。
- 不重写业务逻辑和接口（第三批的口径校准除外，单独评审）。
- 移动管理页只跟随令牌变色，不做专门设计。

1. 三租户切换后，首页、晨读营、我的、课程详情、打卡五个页面无冷灰补丁，无硬编码品牌蓝。

## 实施记录（2026-11-10）

三批都已在工作区实现，对应三份 OpenSpec 变更（`update-miniprogram-warm-paper-tokens`、`redesign-home-morning-hero`、`add-profile-reading-journal`），各自的 `tasks.md` 按实际完成情况勾选，未做的项写明了原因。与方案正文不同的地方：

- **首页主按钮**：方案写的是「开始晨读 → 去打卡 → 今日已完成」单线推进。实际很多书友不经沉浸阅读就直接打卡，所以改为：已打卡即显示「今日已完成」；未读未打卡时主按钮是「开始晨读」，下方保留「直接去打卡」入口。
- **打卡仪式**：只做了日出画面、大号天数、寄语和一个按钮。连续天数和「今天第几位」在打卡页没有可靠数据，没有做；按钮只是关闭并返回，所以文案是「好，明早见」，不是「看看大家的打卡」；「分享今日打卡」没有做。
- **「第 N 天」**：只有在能确定该期课节编号从 0 还是从 1 开始时才显示，否则隐藏。
- **退出未发布弹窗**：「丢弃并退出」会清掉草稿，文案按实际行为写（见 J 节）。
- **小凡的信**：列表数据里没有可靠的已读标记，未读火漆点和首页「小凡给你留了一封信」的提示没有做，只做了信封和信纸样式。
- **共读足迹**：进行中的一期显示「进行中」文字，没有显示进度数字。
- **阅读设置**：字号沿用现有三档。
- **课程九步进度条**：吸顶依赖较新的系统；旧系统上会随页面滚走，点击跳转和高亮不受影响。
- **已补核心链路**：通用主按钮、首页晨读提醒、打卡提交和晨光仪式改用租户深色主题色承载白字；其余历史页面的按钮和成功提示仍按后续页面回归逐步清理。小程序源码体积合计增加约 105 KB，主包是否超限需要在开发者工具里确认。
- **后端**：累计天数和连续天数改为读取时按东八区自然日计算，没有改任何已存数据；新增 `GET /checkins/user/calendar`。未连真实数据库验证。
