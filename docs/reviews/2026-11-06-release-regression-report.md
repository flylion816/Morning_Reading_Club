## 兼容性判断

- `Period`、`Section`、`Enrollment` 新增字段均为可选或快照字段；历史数据无模板时按旧结构返回，相关兼容测试通过。
- 旧小程序没有 `X-Course-Template-Version` 时，历史课程和七个习惯课程不受影响；自定义模板课程返回明确升级提示。
- 旧后台登录响应已补充 `token` 兼容字段。旧后台不会自动轮期 HttpOnly refresh cookie，15 分钟 access token 过期后会要求重新登录，因此建议后台与后端同批发布。
- 新后端会话模型会让已登录管理员在发布后重新登录一次；这是预期的一次性影响，不涉及业务数据重置。
- 免费报名在新后端允许参与互动；旧小程序仍按旧客户端本地区分参与状态，升级后获得完整免费报名体验。
