# 报名模板与阅读配置验收用例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| E01 | 新建期次选课程模板和简洁报名模板；就地新建报名模板 | 选择独立生效，返回保留表单并自动选中 |
| E02 | 简洁报名填姓名和手机号 | 不校验隐藏的性别、年龄、地区、阅读经历；必填错误定位到字段 |
| E03 | 完整版三步报名及 readTimes 条件字段 | 保留原资料与校验，其他课程不固定显示23天、6点 |
| E04 | 拒绝手机号授权、手填无效手机号、切换期次 | 仍可手填，校验正确，不混用旧模板必填与旧价格 |
| E05 | 免费报名、重复点击/重复请求 | 不下微信单，一笔有效报名，free状态可阅读及参与 |
| E06 | 付费提交、取消付款、继续支付 | pending不显示成功，确认付款后才授予权益 |
| E07 | 伪造金额、付款成功、模板版本 | 服务端拒绝或返回真实配置要求确认，不产生错误权益 |
| E08 | 最后名额并发、模板更新与报名并发 | 不超员、不重复占位、不混用表单快照 |
| E09 | 模板停用、跨租户ID、过期编辑版本 | 新绑定受限、历史照常、越权拒绝、并发覆盖拒绝 |
| E10 | 首次报名后修改收费/表单、复制期次 | 配置锁定；复制保留模板但不复制个人资料或订单 |
| A01 | 匿名访问公开已发布课程 | 不要求报名或登录即可读，不自动生成报名 |
| A02 | 匿名或未支付通过详情/搜索/阅读/分享读取受限课节 | 不能绕过服务端权限或读到正文、媒体地址 |
| A03 | 草稿、名单外、跨租户公开期次 | 公开模式不绕过这些限制 |
| A04 | 公开阅读未报名者参与打卡、读取名单 | 不能获得互动或私人名单权限 |
| A05 | 有效free、paid、pending、refunded、withdrawn | 阅读和互动按期次策略及真实权益分别计算 |
| A06 | 关闭招募后已报名者/公开访客阅读 | 已有权益和公开阅读不被招募开关错误关闭 |
| C01 | 历史完整报名、无新配置期次、旧版小程序 | 旧数据可读，不批量改写；新流程不支持时明确提示升级 |
| C02 | 简洁表单统计和导出 | 只统计实际收集项，不收集的资料不计为未知；历史导出兼容 |
| C03 | 新定义、期次、资料及订单备份恢复 | 在全新隔离库验证快照、答案、金额与权益一致 |
| U01 | 桌面期次列表、长编辑表单、390/320px宽度 | 名称和动作可达，弹窗内部滚动，保存栏可见，无横向溢出 |
| U02 | 手机简洁/完整/公开、免费/付费、错误/成功状态 | 表单数量、费用、文案和下一步入口与策略一致 |
