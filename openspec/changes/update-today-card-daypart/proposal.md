# Change: 今日晨读卡随时段和学习状态调整

## Why
首页今日晨读卡目前始终优先引导未读用户开始晨读，下午打开仍出现两节点步骤线和「开始晨读」主按钮，无法反映早晨共读与之后记录感悟的不同需求。

## What Changes
- 用同一张今日课程卡的晨读、记录、完成三种状态替代两节点步骤线。
- 对未完成的书友，05:00–07:29 优先晨读；07:30 后优先打卡，并保留另一个入口。
- 已读未打卡时优先打卡，已打卡时展示完成状态；无社群权限时不显示打卡入口。
- 保留现有课节、课程详情、日签、播客、实录和管理员首页配置；当数据可用时使用真实数据。
- 切换首页、跨越 07:30 或日期变更时更新状态，不新增数据表或改变既有接口权限。

## Impact
- Affected specs: miniprogram-dawn-rituals
- Affected code: `miniprogram/pages/index/`、首页相关测试。
- 用户已确认以暖纸、竹叶和蓝色按钮的参考图为方向；设计调整只涉及今日晨读卡。
