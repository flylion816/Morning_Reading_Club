# 课程模板测试用例

状态约定：以下是待执行的验收用例，并非已经通过的测试。自动化及人工验收均须记录环境、版本、实际结果和失败原因。禁止连接业务数据库执行清理；涉及数据删除的测试仅使用独立创建的临时测试数据库。

## 模板管理

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| T01 | 查看模板列表 | 当前租户可见内置七个习惯模板和本租户模板，不可见其他租户自建模板 |
| T02 | 创建空间管理模板，配置短文本、多行文本、正文、图片 | 名称、类型及顺序保存后重新打开保持一致 |
| T03 | 修改模块名称及顺序并保存 | 模块稳定 ID 不因改名、排序改变，后续绑定使用新版本 |
| T04 | 复制内置模板并修改副本 | 默认模板不变，副本只属于当前租户 |
| T05 | 停用自建模板 | 新建期次不可选，已绑定期次仍可使用 |
| T06 | 输入空名称、重复 ID、非法类型、超长文本、超出模块数 | 前后端均拒绝非法请求并提示，不产生部分数据 |
| T07 | 配置两个正文模块 | 保存失败，提示最多一个正文模块 |
| T08 | 两个管理员基于同一版本编辑 | 后提交的过期版本收到冲突提示，不能覆盖较新的修改 |
| T09 | 伪造其他租户模板 ID 进行读取、修改、复制、绑定 | 服务端拒绝，且不泄露其他租户内容 |
| T10 | 平台管理员未选择租户时写入模板 | 服务端拒绝并提示先选择租户 |

## 手机预览

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| P01 | 预览未保存模板，增删模块、改名、更换类型和调整顺序 | 手机样式预览即时对应草稿，类型使用对应示例内容 |
| P02 | 查看正文和图片预览 | 正文、图片以合理样式呈现，明确标记为模拟效果 |
| P03 | 打开已保存模板预览 | 显示已保存的模块配置，不意外加载其他草稿 |
| P04 | 关闭或刷新草稿预览 | 不创建课节、不发布期次、不把示例内容写入数据库 |
| P05 | 在窄屏操作模板编辑及预览 | 内容可读、主要操作可达，不遮挡保存和关闭按钮 |
| P06 | 在微信开发者工具和真机对照真实课程页面 | 记录预览与真实呈现的差异，名称、顺序及内容类型一致 |

## 期次与课节

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| C01 | 创建期次时选择七个习惯模板 | 新建课节显示原有学习模块 |
| C02 | 期次表单内创建空间管理模板 | 返回时保留已填表单并自动选中刚创建的模板 |
| C03 | 未选模板或选择停用模板提交 | 系统拒绝或仅按约定兼容旧客户端默认行为，不创建错误绑定 |
| C04 | 使用模板创建期次，再修改原模板 | 旧期次快照不变，新期次使用新模板配置 |
| C05 | 空期次更换模板 | 新增课节使用新的快照 |
| C06 | 已有课节的期次更换模板 | 前后端均拒绝，已有内容不变 |
| C07 | 为同一期次创建两节课并填写不同内容 | 两课节模块结构一致，各自内容正确 |
| C08 | 模块留空保存并查看课程 | 学员端隐藏空模块；全部为空时打卡预览显示空状态 |
| C09 | 重命名后新期次填值，编辑再保存 | 值按稳定 ID 关联，不因名称改变错位 |
| C10 | 复制有模板及课节的期次 | 模板快照和课节值复制，沿用现场音视频不复制规则 |
| C11 | 非法模块 ID、类型不符、超长或非法图片地址 | 接口拒绝，不保存非法数据 |

## 执行记录

课节弹窗排版回归：基本信息按网格显示，内容区独立滚动，头部与保存栏保持可见；图片通过“选择图片”按钮打开文件选择器并上传、保存。已通过桌面和390px窄屏浏览器检查、课节相关7项组件测试、类型检查和构建；实际图片选择及保存链路已通过真实浏览器验证。效果截图：`output/course-template-verification/lesson-layout-desktop.png`、`output/course-template-verification/lesson-layout-mobile.png`。

扩展能力回归：三个扩展开关全部关闭时，“扩展信息”标题、时长、结营视频及整个播客组（音频、播客时长、播客介绍）均不渲染；“发布状态”作为课节设置保留。关闭播客但启用其他扩展时，只隐藏整个播客组。缺少扩展配置的历史期次继续显示全部扩展。已通过3项组件行为测试、4项既有视频回归及真实浏览器对关闭/历史两种期次的检查；截图：`output/course-template-verification/disabled-lesson-extensions.png`。
