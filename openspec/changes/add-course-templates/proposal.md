# Change: 可复用的课程模板与手机预览

## Why

现有课程编辑、存储和小程序展示固定使用七个习惯的学习模块，难以承载空间管理、细心细行等不同课程。运营人员需要复用模板，在创建期次时选定适合的结构，并在配置时预览手机呈现效果。

## What Changes

- 新增租户内课程模板管理，预置七个习惯默认模板，支持创建、编辑、复制和停用。
- 模板由有稳定标识、可排序的模块构成，支持短文本、多行文本、正文、图片；正文最多一个，名称可自定义。
- 模板编辑时提供手机样式的即时预览，使用示例内容展示学习详情的大致效果。
- 新建期次选择模板，可从期次表单创建模板并返回选中；绑定时保存独立快照，同一期次所有课节采用一致结构。
- 课程编辑、小程序课程详情和打卡预览按期次快照显示；正文继续支持已有阅读与朗读能力。
- 兼容历史七个习惯期次和复制期次，保护已填写内容并验证旧客户端和备份恢复。

## Impact

- Affected specs: 新增 `course-templates` 能力，仓库目前无现有 `openspec/specs` 基线。
- Affected code: 管理后台模板、期次和课程界面；后端模板、期次、课节、鉴权及同步备份；小程序课程详情、打卡及阅读相关链路。
- 不执行数据库重置或历史数据批量改写；不在本提案阶段修改业务代码。
