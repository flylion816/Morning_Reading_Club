# Change: 随喜记升级为觉察日记（随喜速记 + 觉察静室 + 一周后回访）

## Why
随喜记现在要从首页滑到营地角落、点进页面、再点输入框才能写，写下的触动已经离开了晨读现场；同时书友也需要一个能"向内看"的地方，把情绪和反应慢慢看清，而不是只记一句话。两件事要的节奏完全相反：随喜要快，觉察要慢，所以做成两种写法，而不是让书友先选类型。

## What Changes
- **改名与入口**：随喜记改名为「觉察日记」，营地角落和「我的」里的入口原位替换，页面路径不变（`/pages/joy-notes/joy-notes`）。已有的随喜记全部保留，自动算作「随喜」。
- **随喜速记（要快）**：
  - 首页「今日晨读」卡片的链接行新增「记一句」，沉浸阅读长按段落选「记一条随喜」，都在原页面弹出半屏速记条（键盘直接弹起），不再跳页。
  - 自动带上今天这一课（或长按的那一段和所在课程），保存时仍由服务端校验报名与课程权限；没写完收起时在本机保留草稿。
  - 保存成功后给 3 秒小提示「再记一句」，晨读时可以连着记。
- **觉察静室（要慢）**：觉察日记页上输入框之外多一扇深色的门，进去是五屏流程：停（呼吸三次）→ 看（只写事实）→ 感（选 1–3 个情绪词，分「沉一点的」「亮一点的」两组各八个，找不到合适的词可以自己加一个，加在哪一组就按哪一组算明暗，词只存在本机；可写身体感觉）→ 问（一叩、再叩、三叩，最多三层）→ 择（落到 24 小时内做得到的小动作）→ 收（收成一张卡）。每一问都可跳过，只答一问也能保存；中途退出在本机保存草稿，下次进门询问是否接着写。
- **问题跟着习惯和心情走**：一共八组问题（七个习惯各一组，加一组通用）。按今天或所关联课程的标题识别习惯，识别不出时用通用组。开心和难过的背后都藏着自己在意的东西，所以每组既有给难受时的问题链（看见自己在保护什么、真正想要什么），也有给开心时的「种子」问题链（顺着这份好心情，找到心里在意的那颗种子）；按「感」里选的词决定先问哪一种，问题里带上选的词，「择」和收尾的那句话也跟着换。每条回答连同提出的问题文字一起保存，之后改题库不影响历史。
- **回访来信**：「择」这一屏默认开启「一周后来信」。到期后在东八区早上 6:00 起，由定时任务把一封 `awareness_revisit` 来信送到「来信」，问"后来怎么样了"；书友可以写「后来」（可写多次，每次带日期）或「先不写」；每条觉察最多回访一次。来信里不含笔记文字，卡片内容由客户端凭记录 ID 实时读取。
- **标题**：随喜和觉察都可以起标题（选填，最多 40 字）。随喜在输入框上方、速记条里各有一行细细的标题输入；觉察在「择」那一屏末尾给这一页起名；觉察详情页可以改标题。列表里有标题的以标题打头，搜索也能搜到标题。
- **富文本重点颜色**：随喜的输入框（日记页、速记条）和觉察里的「看」「问」「择」，都用和打卡页一致的富文本：加粗、斜体、下划线、标题、列表、五种颜色，可以撤销重做；默认是普通输入框（速记不变慢），点右下角「Aa」才升级成富文本编辑器。保存时同时保存清洗后的 HTML 和纯文本，搜索、复制、日签和回访来信用纯文本；清洗规则与打卡共用一份。
- **分享**（随喜和觉察都支持，体验与打卡一致）：
  - 入口：列表长按菜单 / ⋯、觉察详情页、静室结束页。分享面板写明「收到的人能看到这一页的全部内容」，可选「谁能看」（关联了期次时：本期书友 / 所有登录的书友），可以随时「停止分享」。
  - 三种方式：发给微信好友（转发卡片）、生成长图（带小程序码，保存或发给好友）。长图里保留标题、重点颜色和排版。
  - 扫码或点卡片直达这一页的只读视图；**没有登录、没有权限、分享已停止或内容已删除，一律回到首页**。收到的人不能再转发这一页。
  - 只有主动分享才会产生链接：打开面板后没有转发也没有生成长图就关闭，这次新开的分享会自动撤销。
- **列表与详情**：列表筛选「全部 / 随喜 / 觉察 / 打卡」。随喜是晨光纸条，觉察是带"夜到晨"色带的卡片；「打卡」只列出本人的打卡，点开去打卡详情，不复制数据。觉察详情把看、感、问、择、后来排成一条时间线。
- **衔接**：长按一条随喜可「从这句开始觉察」；觉察可「做成日签」（用「择」的文字）、「发成今天的打卡」（内容写入打卡草稿，可见范围到打卡页再选）。

## Out of Scope
- 不接入 AI，问题全部是预先写好的静态内容，笔记内容不会发给任何第三方。
- 觉察日记默认仅自己可见，不点赞、不评论；要给别人看，只能通过「分享」这一页，或发成打卡。
- 每月回看统计、「随喜给 TA」告知书友，留待后续变更。
- 分享不支持朋友圈的单页模式（那里不能请求接口）；想发朋友圈请用长图。
- 分享内容是这一页的实时内容，不做快照；想收回就「停止分享」。
- 随喜与觉察不做相互转换后的数据合并：「从这句开始觉察」只是把文字带入新觉察的第一问，原随喜保留。

## Impact
- Affected specs: `awareness-journal`（新增；继承并扩展尚未归档的 `joy-notes`）
- 后端：`JoyNote` 模型新增 `kind`、`awareness`、`title`、`contentHtml` 及觉察各字段的 `*Html`；新增 `JoyNoteShare` 集合和 `/joy-note-shares` 接口；富文本清洗从打卡抽成共用工具 `utils/rich-text.js`；`joyNote.controller` / `joyNote.routes` 新增觉察创建、后来、跳过回访、回访卡片、列表筛选；新增 `awareness-revisit.service` 定时任务；`Notification` 新增类型 `awareness_revisit` 与 `data.joyNoteId`；`server.js` 启动任务。
- 小程序：`pages/joy-notes`（改版、新增静室页、详情页、分享落地页和分享面板组件）、新增 `components/rich-editor`、`pages/index`（记一句、营地角落文案）、`pages/reading-mode`（原地速记）、`pages/profile`（入口文案）、`pages/notifications`（回访来信）、新增 `components/quick-note`、`services/joy-note.service.js`、`utils/awareness-*.js`。
- 数据：只新增可选字段与一个通知类型，不需要迁移，不需要运行任何初始化脚本；既有记录缺少 `kind` 时一律按随喜处理。
