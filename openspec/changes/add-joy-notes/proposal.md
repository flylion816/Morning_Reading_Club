# Change: 随喜记

## Why

书友在晨读和交流中听到的触动往往分散在聊天记录里，需要一个能快速记录和按期次回看的私人空间。

## What Changes

- 新增仅本人可见的随喜记，支持无需标题的快捷记录、倒序列表、按期次筛选、编辑和删除。
- 期次和课程为可选关联；只有本人有效报名且具有阅读权限的期次可被选择和绑定，课程必须属于所选期次并已发布。
- 后端在创建、修改关联和读取可选期次、课程时独立校验用户、租户、报名与权限；不得仅依赖客户端筛选。
- 首页营地角落末尾增加入口，按入口数量自适应布局；「我的」增加备用入口，方便不在当前营期时回看。
- 保存失败保留输入，历史记录的内容仍由本人管理；已失去访问权限的期次和课程不再展示受限的来源信息。

## Impact

- Affected specs: `joy-notes`（新增）
- Affected code: 小程序首页、个人中心、随喜记页面和服务；后端随喜记模型、接口和测试。
- 无数据库重置或数据迁移；新增私有记录集合。
