## 设计与权限

- 随喜记是用户自己的文本记录，不要求关联期次或课程。记录按用户和租户隔离，接口响应设置 `private, no-store`，不提供公开、分享或管理员读取接口。
- 可关联期次从当前租户内本人有效报名中取得：状态为 `active` 或 `completed`，支付状态为 `paid` 或 `free`，且报名未删除；同时遵循项目现有期次阅读权限。
- 课程选择仅包含所选期次中已发布的课节。接口在取得可选期次、读取课程、创建记录和更改关联时独立检查权限和归属。
- 用户原有的报名失效后，个人记录内容仍可查看、编辑和删除；不可访问的期次、课程名称不再返回。用户可以解除旧关联，但不可重新绑定无权期次。
- 首页按四个入口两列、三个入口三列、两个入口两列、一个入口横排展示。「我的」备用入口不依赖当前期次或付费状态。
- 保存期间禁止重复提交和修改输入；请求失败保留输入。切换账号时清空上一账号的页面记录和未提交内容。

## 存储与运行验证

- 记录写入新的 MongoDB 集合，租户插件负责强制注入租户条件。当前项目的 MongoDB 全库备份方式可覆盖该集合；现有 MongoDB→MySQL 同步清单没有包含该集合。
- 已用独立 MongoDB Memory Server 和合成数据验证认证、用户及租户隔离、有效报名、未发布或不匹配课程、权限失效以及页面逻辑到真实 HTTP 接口的记录、筛选、编辑、删除流程。
- 本地实现时已在微信开发者工具中确认首页四入口布局、个人中心入口和随喜记页面的实际渲染。2026-11-15 用户确认最新代码及小程序已发布，线上新增接口对未认证请求返回 401；本次核对未以真实账号验证线上保存、课程选择或真机交互。
