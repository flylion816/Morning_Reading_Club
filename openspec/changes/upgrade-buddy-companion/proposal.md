# 读伴升级：从「两个状态点」到「一段同行」

## Why
读伴页现在只有两个头像、四个「读 / 记」圆圈和一次轻拍，看不出两个人在一起做什么；首页只在最底部的「营地角落」里有一张小卡，要划到底才看得到；通知里看不出是哪一期的读伴，两期各有读伴时容易混。

## What Changes
- 规则不变：**每一期只有一位读伴**（`BuddyPair` 唯一约束）。结束后可再找，但同一期内不会再配回同一个人。
- 状态：`GET /buddies/period/:periodId` 增加 `periodName`、`pairedDay`、`highFive*`、`gift*`、`waitingCount`；`buddy` 对象的字段保持不变（仍不含用户 ID）。
- 新互动：
  - 击掌 `POST .../highfive`：两人今天都读完才可以，每人每天一次，对方收到站内通知。
  - 送一句 `POST .../gift`：只能选预设短句（不开放自由输入），每人每天一句，对方当天在读伴页看到，并收到站内通知。
  - 轻拍新增一句预设「不急，慢慢来」。
- 同行足迹：`GET .../overview` 增加 `trail`（每天一格：一起 / 只有我 / 只有 TA / 未到）、`timeline`（成为读伴、第一次同一天读完、击掌、送的一句）、`highFiveCount`、`giftCount`；`sharedDays` 只统计结伴之后。
- 结营纪念：`GET .../souvenir`（结伴天数、一起读完的天数、击掌次数、对方送的第一句）；`POST .../rematch` 记录「下一期还做读伴」的意愿，**只有双方都点了才会生效**，对方是否点过不对外泄露。
- 续伴：下一期任意一方点「想要读伴」时，若上一期的读伴双方都点过续伴、对方也已报名这一期且还没有读伴，则直接配成一对。
- 通知：新增 `buddy_highfive`、`buddy_gift`；轻拍通知标题带期次名。
- 首页：在天空区和「今日晨读」之间新增一条读伴卡（已配对时显示），营地角落里的读伴卡只保留名字和「同行第几天」。
- 读伴页重构：同行卡、状态一句话、轻拍与送一句、同行足迹与时间线、结营纪念卡、更新介绍文案（现在能看到 TA 的公开打卡）。

## 读伴专属互动与「来信」（追加）
- 读伴关系对营里**公开**：打卡列表、详情带上作者的读伴 ID，读伴给这篇打卡点的赞排第一并带「伴」角标，读伴的评论置顶并带「读伴」标签。
- 读伴回应：`POST /buddies/period/:periodId/react`，对读伴的一篇打卡回一句预设短句（只存 key，不开放自由输入），每篇一次，显示在这篇打卡的最上面；对营里可见。
- 读伴写了打卡：单独给读伴发 `buddy_checkin` 通知（私密打卡不通知）。
- 通知数据：`dispatchNotificationWithSubscribe` 在发送人是收件人的读伴时写入 `data.fromBuddy`；点赞、评论通知补上 `sectionTitle`、`commentPreview`。
- 小凡看见：读伴的点赞同样带 `fromBuddy`，在来信里是暖色卡片并带「伴」标记（小凡看见页面目前没有点赞人列表，所以只在来信里体现）。
- 通知页改名「来信」：以人为主、按天分组、同一篇打卡的点赞合并（评论不合并）、读伴在同一篇打卡上的点赞/评论/回应合并成一条暖色来信、申请看见可直接在来信里处理、长按出菜单（标为已读 / 删除）、筛选改为 全部 / 未读 / 等我回应。
- 读伴页：TA 的新打卡带小圆点，回应过的显示回应了哪一句；回应进时间线，纪念卡多一项「次回应」。

## 邀请读伴（追加）
- 从本期学员里挑一位发邀请，对方同意后才结成读伴：`GET .../candidates`（本期已报名、没有读伴的学员，可按昵称搜）、`POST .../invite`、`POST .../invites/:id/respond`、`POST .../invites/:id/cancel`；新增 `BuddyInvite` 集合。
- 规则：同一期每人同时最多 5 条待回复邀请；已有读伴的人要先结束才能邀请别人；结束后可以重新邀请（包括同一个人）；对方已先邀请了我时，直接当作同意；同意后双方其余待回复的邀请和随机等待申请自动作废。
- 对方在来信里（`buddy_invite` 通知，带邀请当前状态）或读伴页都能同意 / 先不了；邀请人收到 `buddy_invite_accepted`。婉拒不通知邀请人。
- 随机配对保留不变。

## Out of Scope
- 送一句暂不支持「送自己的课程摘抄」，后续再做。
- 读伴之间的点赞、评论不进读伴页时间线（只记击掌、送一句、回应）。
- 纪念卡暂不支持保存成图片，先在页面内展示。
- 击掌、送一句只发站内通知，不发微信订阅消息。

## Impact
- 后端：`BuddyPair` 模型新增 `highFiveLog`、`gifts`、`rematchVotes`；`buddy.service` / `buddy.controller` / `buddy.routes`；`Notification` 类型枚举。
- 小程序：`pages/buddy`、`pages/index`、`pages/notifications`、`services/buddy.service.js`。
- 数据：只新增可选字段，不需要迁移，不需要运行任何初始化脚本。
