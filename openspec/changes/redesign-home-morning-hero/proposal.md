# Change: 小程序「晨光」第二批——首屏与仪式

## Why

首页第一屏现在是头像、昵称、签名和一个数字，本质是个人名片，不知道现在是清晨，也不告诉用户今天是第几天、读什么；打卡成功是 7 套动画随机出，与晨读的气质无关；登录页是整屏主色加悬浮白卡，会成为晨光之后最「旧」的一屏。第二批把首屏还给今天的晨读，给打卡和读完做晨光仪式，并换上破晓登录页。依赖第一批的暖纸与晨光令牌。

## What Changes

- 首页首屏改为「晨光问候区」：问候、日期、期次与第几天，背景随时段变化（破晓、白天、黄昏、夜晚），只有这一块变色；首页导航底色跟随时段。
- 新增旅程进度：一条地平线上按期次天数分刻度，太阳停在今天，并显示连续与累计天数。
- 新增「今日晨读卡」：课程标题、今日一句、已打卡书友头像、三步进度、单一主按钮；原四个并排按钮降为文字入口。头像缩小到右上角，个人签名移到「我的」（由第三批展示）。
- 打卡成功样式 C 升级为晨光仪式，读完提示同步成同一套视觉；配一次中等强度震动；打卡编辑页输入框提示语改为当天「想一想」问题。**不改后端**，后台庆祝配置照常生效。
- 点赞增加心形弹跳；动效按三档时长，并尊重系统「减少动态效果」。
- 新增一套线描空态插画（摊开的书、台灯、信封、小树苗），首页与「我的」改用骨架屏，列表页「加载中」文字改为骨架行。
- 登录页改为「破晓」登录：上半屏租户主色渐亮成晨光，下半屏暖纸承载登录区，白色线描徽记，衬线品牌名；协议勾选、快捷登录流程与「稍后登录」不变。
- 建议各租户后台默认只启用庆祝样式 C 与 B（配置层建议，不改代码）。
